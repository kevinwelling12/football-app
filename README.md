# Football

Kevin's football tracker: Premier League, Bundesliga, Champions League, MLS, NWSL and USL Championship, plus La Liga, Serie A, Ligue 1 and the EFL Championship.
Live at https://kevinwelling12.github.io/football-app/

- Results, fixtures, odds and live scores from ESPN's public API; manual entry for anything in progress.
- Own prediction model (Elo + time-weighted Dixon-Coles on ten seasons, shots-based xG proxy) blended with betting lines.
- Projected tables, race odds from 10,000 simulated seasons, playoff brackets, proven clinches and this-round scenarios.
- FotMob Predict picks that maximise expected points (2 for the result, +1 for the exact score).

Start with CLAUDE.md. Model and backtests: docs/model.md. Cloud sync setup: docs/firebase-setup.md.
